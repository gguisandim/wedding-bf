# Casamento App

Estrutura inicial do sistema administrativo e do convite de casamento.

## Abrir no VS Code

Extraia a pasta e execute:

```bash
cd casamento-app
code .
```

## Instalar dependências

```bash
npm install
```

## Executar localmente

```bash
npm run dev
```

Acesse:

```text
http://localhost:3000
```

## Rotas iniciais

- `/login`
- `/painel`
- `/painel/convidados`
- `/painel/mesas`
- `/painel/tarefas`
- `/painel/fornecedores`
- `/painel/financeiro`
- `/painel/presentes`
- `/painel/fotos`
- `/painel/configuracoes`
- `/convite`
- `/confirmar/[codigo]`
- `/fotos`
